# HalloFelix von InsurMagic

HalloFelix answers calls and WhatsApp messages for insurance brokers in Germany, Austria and Switzerland. After connecting, you can:

- summarize recent calls with transcripts, summaries and captured data,
- look up and create customers,
- create outbound call campaigns as drafts and manage their status,
- read and adjust the phone and WhatsApp assistants,
- work the WhatsApp inbox: read chats, reply, add notes and labels, manage templates.

Starting a campaign places real phone calls and sending WhatsApp messages contacts real customers.
